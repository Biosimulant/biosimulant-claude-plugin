# Start or continue an investigation

1. For existing work, search the signed-in account with `project_search` or `session_list` when available. Use the linked lab or session to narrow ambiguous names. Read the matching session with `session_resume` and saved notes with the available note tools; use the linked lab and runs to verify what happened.
2. Say what has been tried, what evidence or results are saved, and what remains open. Link to the saved work when the server supplies a stable link. Opening or summarizing an investigation does not require creating another session, changing a lab, or starting a run.
3. For new research, find relevant evidence through the connected service and identify the source, what it supports, and any gap that affects the question. Create a Studio session or save a note only when requested. Respect the session's lab, ownership, and current approval settings. Keep research notes separate from execution approvals.

Use the [Biosimulant workflow guide](workflow-guide.md) when deeper guidance is needed, including session approvals, lab edits, file transfer, hosting, and publication. If a capability is missing, report what you could verify and offer a path through Studio when one is available.

Use readable names and plain English when telling the user what you found.

Example: “Pick up my protein-binding study. What have we tried, and what's still open?”
